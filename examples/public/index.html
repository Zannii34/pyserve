PyServe

A web server built from scratch in Python LIVE

Try the API

  • /api/ping — health check
  • /api/time — current server time
  • /api/echo — see your request headers
  • /api/users/42 — path parameter demo
  • /stats — live server statistics

Try with curl

curl http://localhost:8000/api/ping
curl -X POST http://localhost:8000/api/echo -d "hello"
curl -I http://localhost:8000/

Built with

  • Raw TCP sockets + threading
  • HTTP/1.1 parser (no frameworks)
  • Middleware chain with rate limiting + compression
  • Path traversal protection
